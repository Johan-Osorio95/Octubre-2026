Presentación de mi web.

Mi web trata de una tienda llamada "Re-Tonadas", la cual se encarga de vender instrumentos y componentes músicales.

Tiene cuatro secciones:

Mi pedido:

Es la sección donde el usuario verá sus productos comprados y el seguimiento del Producto.

Instrumentos:

Es la sección donde el usuario encontrará más productos para comprar.

Inicio:

Es la sección principal donde se verán los instrumentos en promoción.

Iniciar sesión:

Es la sección donde el cliente podrá ingresar a su cuenta o registrarse con nosotros.

Aspectos visuales:

Es una página muy sencilla, con un aspecto más clásico y de colores sólidos. Se le implementó dos colores base, que son el color gris y el azul oscuro. Y la estructura es muy simple, contiene 4 datos de navegación (Mi pedido, Instrumentos, Inicio, Inicio de sesión), un título, el Header y el Footer, un logo, y las imagenes de los productos.

Orden de mi código:

Mi código lo tengo organizado en alíneamento entre el código HTML y el código de CSS, intento organizar todo de modo que sea más fácil para leerlo

Las técnica que he utilizado ha sido Flexbox, no obstante, como recién estoy iniciando, no tengo una técnica estructurada, pero, sí me gustaría implementar la técnica diseño responsive, ya que se enfoca bastante para que la página funcione lo mejor posible en cualquier pantalla.

Reutilizo los códigos base de la página, como el header, footer, y el main, para mantener la página lo mas similar a la original, luego agrego el diseño, o material que necesito para esa página.
